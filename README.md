# 🎓 Student Management System – Java OOP

A simple **Student Management System** developed using Java to demonstrate fundamental Object-Oriented Programming (OOP) concepts such as **Encapsulation, Constructors, Getters, Setters, and the `this` keyword**.

## ✨ Features

- 👨‍🎓 Create and manage student information.
- 🔒 Use private instance variables to implement Encapsulation.
- 🏗️ Initialize student details using Default and Parameterized Constructors.
- 📥 Retrieve student information using Getter methods.
- ✏️ Update student information using Setter methods.
- 🔑 Use the `this` keyword to differentiate instance variables from constructor parameters.
- 📋 Display student details using the `displayDetails()` method.

## 📚 Java Concepts Covered

1. **Class and Objects** – Creating a Student class and its objects.
2. **Encapsulation** – Declaring instance variables as private.
3. **Default Constructor** – Initializing default student values.
4. **Parameterized Constructor** – Initializing student details during object creation.
5. **Getters** – Accessing private instance variables.
6. **Setters** – Updating private instance variables.
7. **`this` Keyword** – Referring to the current object's instance variables.
8. **Methods** – Displaying student information using `displayDetails()`.

## ⚙️ Application Features

### 👨‍🎓 Student 1 – Default Constructor

- Creates a Student object using the no-argument constructor.
- Assigns student details using setter methods.
- Displays student information using the display method.

### 👩‍🎓 Student 2 – Parameterized Constructor

- Creates a Student object with predefined student details.
- Initializes values directly through the constructor.
- Displays student information using the display method.
